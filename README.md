# hard-assets-research
Investment Research for Real Assets

## Licence & disclaimer

© 2026 Hard Assets Research. Research notes published for personal use.

**Not investment advice.** Nothing in this repository is a recommendation to buy or
sell any security. `conviction` and `froth` are the author's own subjective scores —
defined in `data/glossary.json` — not analyst ratings. Prices are delayed, unaudited,
and reported in local currency without FX conversion. Since-inception performance
tracks are published including when they are unflattering; the trailing table is
labelled retrospective because it measures composition, not skill.

Live: https://joeedessa.github.io/hard-assets-research/

## Working on this repo

- **`index.html` is the source of truth.** `widgets/widget_combined.html` is
  GENERATED by `python3 scripts/sync_widget.py`; CI fails on drift. Never hand-edit
  the widget copy.
- **[docs/QA-LOG.md](docs/QA-LOG.md)** — every real defect found in this dashboard,
  organised by failure class, with the standing check that catches each class. It
  opens with a pre-flight checklist. **Read it before shipping a change, and append
  to it after finding a bug.** Most defects here were not crashes: they were
  confidently phrased, correctly rendered statements that were false.
- Repeatable audits, none of them CI gates:
  - `python3 scripts/audit_schema.py` — data fields the renderer never reads.
  - `python3 scripts/audit_schema.py --symbols` — dead tickers still priced as live.
  - `python3 scripts/verify_trends.py [TICKERS]` — trend maths recomputed from raw
    price series by a different code path.
